# N100 Financial Intelligence Platform

## Project Overview

The N100 Financial Intelligence Platform is a financial analytics system designed to analyze 92 Nifty 100 companies using financial statements, valuation metrics, stock prices, sector information, and peer group analysis.

## Objectives

* Build an ETL pipeline for 12 datasets
* Calculate 50+ financial KPIs
* Generate company health scores
* Develop investment screeners
* Create sector and peer analytics
* Generate automated reports
* Build an interactive Streamlit dashboard

## Datasets

Core Datasets:

* companies.xlsx
* profitandloss.xlsx
* balancesheet.xlsx
* cashflow.xlsx
* analysis.xlsx
* documents.xlsx
* prosandcons.xlsx

Supporting Datasets:

* sectors.xlsx
* stock_prices.xlsx
* market_cap.xlsx
* financial_ratios.xlsx
* peer_groups.xlsx
